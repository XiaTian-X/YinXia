# 设计方法：从策略到精修

> logo-workflow 第 0、2、3 步的设计方法参考，适用于各类标志：字标、图形、徽章、吉祥物，汉字、拉丁字母或纯图形。
> 流程与命令以 SKILL.md 为准，这里只讲怎么想、怎么画、怎么查。含中文或拼音的标志另见 [chinese-typography.md](chinese-typography.md)。

## 1. 原则

1. **标识，不是说明**：标志让人认出品牌，不负责介绍业务。一个标志只装一个想法。
2. **一句话说得清**：说不清，看一眼也读不懂；能套到竞品身上，说明还不是概念。
3. **简洁但不平庸**：先减到想法清楚，再留一个属于这个品牌的细节。
4. **相关但不直白**：表达气质与态度，不要把产品照着画出来（咖啡店画咖啡杯、牙科画牙齿）。
5. **有区分度**：先了解同行业长什么样，再刻意避开。
6. **大小都能用**：16px 图标和大幅招牌，单色印刷、反白、刺绣、烫金都要成立。
7. **结构先于颜色**：颜色是最后一层。只靠颜色才认得出的标志，一到单色场景就失效。
8. **经得起时间**：建立在概念上，不建立在流行效果上（渐变、投影、玻璃质感）。
9. **能长成体系**：标志要能衍生出图标、图案、动效和子品牌，不要只在白底上单独评判。
10. **坚持策略，细节保持开放**：按简报解释取舍，同时认真对待用户的反馈。

## 2. 策略：把简报变成视觉线索

**品牌性格形容词**：访谈时请用户给 3–5 个，写进 brief 的“核心关键词”。它们会直接转成视觉线索，例如：

| 形容词 | 可能的视觉线索 |
|---|---|
| 可靠、稳重 | 对称、水平基线、厚实笔画、封闭外形 |
| 灵动、轻快 | 斜向动势、开口、留白多、细笔画 |
| 温暖、亲和 | 圆角、柔和曲线、暖色 |
| 精确、专业 | 几何构造、一致的角度与线宽、冷静配色 |
| 传统、人文 | 书写笔意、衬线或楷宋类字体、印记 |

**行业惯例与常见套路**：先列出主要同类品牌（写进 brief 的“行业/领域”）和这个行业常见的图形与配色（写进“不喜欢的风格（禁忌）”）。默认不用，除非能给出新的形式。常见例子：

- 科技 / AI：神经网络节点、电路、大脑、紫蓝渐变、闪光星形
- 金融：盾牌、向上箭头、地球、深蓝
- 餐饮 / 咖啡：咖啡豆、蒸汽、杯子、厨师帽
- 教育：书本、学士帽、灯泡
- 宠物：爪印、骨头、猫狗剪影
- 健康 / 环保：叶子、心形加十字、绿色
- 地产：屋顶、房子轮廓、钥匙

**词汇联想**：把名称、业务、性格、承诺分别展开成名词、隐喻和反义词，找出几组之间的交叉点，概念往往从交叉点里来。
例如：名称“夏”→ 季节、蝉、荷、日光、炎热；性格“清朗”→ 透明、留白、水；交叉点“荷叶上的日光”。

## 3. 标志结构：先定做哪一种

| 结构 | 说明 | 适合 | 风险 | 印夏版式 |
|---|---|---|---|---|
| 纯字标 | 名称本身就是标志，常带定制字形 | 名称短、好读 | 16px 下放不下长名称 | `primary` / `wordmark-*` |
| 单字或字母成标 | 取一个字或首字母做成图形 | 名称长、需要方形图标 | 必须同时读得出字和图形 | `icon` |
| 组合字母 | 多个首字母组合成一个图形 | 字母缩写已被熟知 | 容易像别家的缩写标志 | `icon` |
| 图文组合 | 图形加名称，位置和比例固定 | 大多数新品牌 | 组合在小尺寸下失效，要准备纯图形 | `primary` + `horizontal` + `icon` |
| 纯图形（具象 / 抽象 / 几何） | 不带文字 | 已经有知名度的品牌 | 新品牌只用图形很难被记住；几何图形容易撞车 | `icon` |
| 徽章 / 印记 | 文字和图形装在一个外框里 | 传统、手作、机构 | 细节多，小尺寸糊 | `primary`，另做简化版 `icon` |
| 吉祥物 / 角色 | 拟人化的形象 | 面向大众、年轻用户 | 复杂度失控 | `primary`，另做头部或剪影 `icon` |

**从一开始就规划小尺寸版本**：图文组合在 16px 下几乎都会失效，要么有一个能独立的图形或单字，要么准备简化版的 `icon.svg`。
常见配置：主版用于大多数场合，图形或单字用于方形和小尺寸场景（App 图标、头像、favicon），三者共享同一套视觉基因。

**比较时要拉开差距**：探索至少两种不同的结构，不要只在同一种结构里换字体。

## 4. 概念筛选

1. 写 **8–12 个一句话概念**，分布在不同结构上；每个都要有一个属于这个品牌的转折。
2. 按 5 项快速打分（各 1–5 分）：想法是否清楚、区分度、简洁、与简报的关联、小尺寸表现。
3. 选出**分数高且彼此差异最大的 2–3 个**（通常 3 个），建成方向 A / B / C。不要在会被淘汰的想法上精修。
4. 用 `./logo decision <slug> shortlist-concepts --title "概念筛选"` 记录：长名单和分数逐条写在“选项与分析”，入选理由写在“最终结论”，方便以后回看为什么没选别的。
   长名单对用户有帮助时可以给用户看，让用户早一点参与方向判断。
5. 动手前想一想：这个概念是不是和熟知的某个标志很像？“看起来眼熟，但又不是你的”，多半是别人的。

## 5. 起稿：先写构造，再写 SVG

- **先用文字描述构造**：用哪些基本形、圆角半径多少、角度多少、网格单位多大，写进 notes.md 的“改动说明”，再写 SVG。
- **先做黑白**：第一版用一种深色（色板中最深的颜色）画结构，确认图形本身站得住再上色；彩色只是最后一层。
- **几何要干净**：
  - 锚点尽量少；圆形结构用圆弧，不要用很多小段曲线逼近；
  - 角度用整数，常用 0 / 15 / 30 / 45 / 60 / 90°，避免 44°、31° 这种“差一点”的角度；
  - 同类元素用一致的线宽和圆角；
  - 负空间用真正的镂空（`fill-rule="evenodd"` 或路径挖空），不要用白色图形盖住。
- **细节不要太小**：小于整个标志 1/48 的细节、发丝细线、很窄的缝隙，在小尺寸下都会消失或粘连。
- **每次有意义的修改都开新版本**（`./logo version`），不要覆盖，方便对比和回退。

## 6. 精修

**光学修正**（几何上准确不等于看起来准确）：
- **超出边界**：圆形和尖角要比方形略大约 1–3%，才显得一样大；圆形放在方形旁边时，要略超出上下边线。
- **视觉居中**：图形放在框里时，视觉中心应略高于几何中心；三角形等上窄下宽的图形，按视觉重心而不是外框居中。
- **水平线略细**：同样粗细时，横线看起来比竖线粗，可以把横向笔画略微减细。
- **反白版略细**：深底上的浅色图形看起来更粗，需要时用 `<版式>.reversed.svg` 提供略细、间隙略大的版本。
- **曲线衔接要顺**：直线直接接圆弧的地方曲率突变，看起来会鼓出一块（像骨头的两端），要用更平缓的过渡曲线衔接。

**交接与字形**：
- 逐个检查笔画相交和相接处：不要有意外的缺口、细缝、鼓包和墨阱。
- **字形测试**：改造过的每个字（汉字、字母）第一眼是否仍然读得出？读成别的字就要改。

**平衡**：整体是否稳定，有没有无意中倾斜；左右、上下的重量是否分布均匀；线宽是否一致；纯图形尽量接近方形，便于放进图标和头像。

## 7. 自查清单（每个版本都要过一遍）

`./logo preview` 的三行对应前三组检查。看完把结论写进 notes.md 的“自查”，没检查的写“未检查”，不要声称没做过的检查。

1. **配色**（第一行）：彩色 / 单色 / 反白都成立，单色版没有糊成一块。
2. **小尺寸**（第二行）：16 / 32 / 64px 下想法还在；间隙和笔画够粗，不行就简化或准备 `icon.svg`。
3. **结构**（第三行）：
   - 剪影：去掉颜色和内部留白，只看外轮廓还能不能认出（带整块底板的标志，剪影就是底板外形，这时看单色版）；
   - 眯眼：模糊后主要形状是否清楚，有没有一团乱的部位；
   - 镜像、倒转：有没有意外的形象或不好的含义。
4. **字面直白**：是不是只是把产品画了出来？是就再推一步，或者放弃这个概念。
5. **区分度**：凭对行业的了解，或请用户在自己的设备上把它和同类品牌的标志并排比较，是否一眼能分开；是否和某个熟知的标志相似。不要把他人的标志存进仓库或登记为概念图。
6. **同等完成度**：和优秀标志放在同样大小时，是否显得一样精致，而不是像草稿。
7. **使用场景**：逐个过一遍：
   - favicon、App 图标、方形头像（需要单独的图形或堆叠版）；
   - 单色印刷、烫金、刺绣（不能有渐变和细线）；
   - 大幅招牌（细线放大后是否仍然好看）；
   - 动效（有没有自然的出现和消失方式）。
   在三个以上场景中失效的方案不适合做主版。
8. **凭记忆能否画出来**：看 30 秒后凭记忆画，画不出来说明细节太多。

## 8. 出手前的危险信号

- 行业套路原样照搬，或者是剪贴画式的直白图形。
- 用没改过的现成字体打出首字母，或者默认字重的几何无衬线，没有任何属于自己的细节。
- 没有概念上的理由却用了三种以上颜色；用渐变、阴影掩盖不够好的图形。
- 过小的细节、发丝线、小尺寸下会合上的窄缝。
- 差一点就对齐的角度、锚点过多导致的波浪曲线、粗细不一的笔画。
- 需要一段话才能解释清楚的概念。
- 和已有的某个标志很像。

## 9. 展示与评审

- **先看结构再看颜色**：先用 `./logo compare <slug> --mode mono` 给用户看单色对比，再看彩色对比；颜色容易引发个人喜好的争论。
- 每个方向只写一句话理念（direction.md 中已有），加 2–3 条与简报的关联，以及一个坦诚的风险。
- 一次给 2–3 个差异明显的方向就够了，太多相似的方案会让用户无从选择。
- 用户的意见原样追加进 notes.md；选定方向时用 `./logo decision` 记录取舍。

## 10. 实事求是

- **商标**：无法保证能注册商标或不侵权，正式使用或注册前应由专业机构做商标检索与近似查询；结论写进 guide.md 的“商标与授权”。
- **字体**：只用已登记并确认授权的字体，所有文字都要转曲（见 SKILL.md“文字转曲”）。
- **渲染**：看不到渲染结果就要说明，不要声称做了没做过的测试。
